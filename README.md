# KulturCheck A1 – Week 5

Interactive evaluation project for the internship task **Evaluation of Cultural Integration in German Language Learning**.

## Features
- Cultural integration strategies
- Quantitative and qualitative metrics
- 7-step evaluation framework
- Hypothetical 20-learner case study
- Practical recommendations
- Interactive evaluation quiz
- Responsive lightweight design

## Run
Open `index.html` directly in a browser or use VS Code + Live Server.
